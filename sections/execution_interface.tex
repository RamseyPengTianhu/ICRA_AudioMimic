\subsection{Robot Reference Integration and Execution}
\label{sec:robot_execution}

As shown in Fig.~\ref{fig:overview}(b), committed
robot-native motion is delivered to a pretrained
SONIC whole-body controller~\cite{luo2026sonic}.
A reference bridge reconstructs root motion in the
fixed sequence coordinate system, maps joints to
the controller convention, and resamples the
30\,Hz reference onto a continuous 50\,Hz grid.
Only the committed prefix is delivered;
the remaining prediction is discarded before replanning.

SONIC remains frozen and combines the consumed reference
with measured robot state to produce control actions.
The generator updates its latent history from the
committed discrete codes and continuous residuals,
and reconstructs its next boundary state from the
corresponding decoded motion.
Thus, reference-derived context supports subsequent
generation, while measured-state feedback closes
the controller's physical execution loop.
